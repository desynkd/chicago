keeping the filename — the main README links to them by name.

| `wip-limit.png` | The refusal. With the limit at 3 and 3 projects active, activate a fourth and capture the notice while it is still on screen. |

Capture from a real vault so the cards hold real project names — a board full
of "Test 1 / Test 2" undersells what the thing is for. Use whichever theme the
board looks best in; every colour resolves to a theme variable, so nothing is
misrepresented by picking one.

match the placeholder dimensions.
